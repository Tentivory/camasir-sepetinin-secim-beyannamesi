# Çamaşır Sepetinin Seçim Beyannamesi

> Kirli çamaşırları temsil eden resmi seçim beyannamesi, sandık protokolü ve oy pusulası üretim yazılımı.  
> Çok ciddi. Hiç komik değil. Sepet artık sandıktır.

## Kuruluş Amacı

Bu yazılım, Türkiye Cumhuriyeti sınırları içinde bulunan her çamaşır sepetinin siyasi iradesini belgelemek üzere tasarlanmıştır. Sepet yalnızca kirli kumaş deposu değildir; bir temsil organıdır. Makine döner, demokrasi döner.

## Yükleme Şartları

- Python 3.8+
- Temiz vicdan (zorunlu değil, tavsiye edilir)
- En az bir gerçek çamaşır sepeti (sanal sepetler geçersiz sayılır)

```bash
python3 secim.py
```

Çıktı, resmi Form 42-KIRLI belgesidir. Yazıcıdan çıkarıp sepetin içine koymanız yeterlidir. Mühür kendiliğinden yapışır.

## Anayasal Maddeler (Özet)

1. Sepete atılan her parça eşit oy hakkına sahiptir.
2. Çoraplar çift halinde oy kullanamaz; bu tekelleşmedir.
3. Havlu kendi kendini kurutamaz, devlet kurutur.
4. Yırtık diz anayasal ayrıcalık değildir, onarım hakkıdır.
